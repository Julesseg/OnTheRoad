# on-the-road

Personal React Native (Expo) road-trip itinerary app. Version 1 is iOS-only
and stores data locally as JSON files.

## Issue tracker

Issues live in GitHub Issues at `Julesseg/OnTheRoad` and are accessed with the
`gh` CLI. See `docs/agents/issue-tracker.md`.

When a pull request implements an issue, include a separate `Closes #<n>` line
in its body so GitHub closes the issue after merge. Use one keyword for each
issue, such as `Closes #7, closes #8`. Valid keywords are `close`, `closes`,
`closed`, `fix`, `fixes`, `fixed`, `resolve`, `resolves`, and `resolved`.

## Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

## Domain docs

The repository uses `CONTEXT.md` and `docs/adr/` as its domain record. See
`docs/agents/domain.md`.
